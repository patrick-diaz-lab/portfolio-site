Eine Stufe von Vision nutzt das offizielle Claude Code auf meinem Abo statt über die API. Sie beantwortet nur Nachrichten, die ich selbst mit einem ausdrücklichen Befehl schicke, und sie ist die einzige Ausnahme von der Regel, dass jeder Modellaufruf über das [Gateway](/de/vision/litellm-gateway/) läuft.

Weil sie ein vollständiges Agent-Werkzeug ist und nicht ein einzelner Modellaufruf, läuft sie innerhalb mehrerer Schichten: ein eigenes Netz, ein frischer Workspace für jeden Aufruf, eine Prüfung dessen, was tatsächlich geladen wurde, und dieselben lesenden Werkzeuge wie das starke Modell. Diese Seite nennt diese Schichten und warum es jede gibt; die genaue Konfiguration bleibt privat.
