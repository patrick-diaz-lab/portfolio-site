### Jeder Server hat einen Bereich für Evals

Jeder Server hat einen zweiten, getrennten Bereich, der nur Testdaten liefert: die Docs des Repos, ein Seed-Set mit erfundenen Notizen, Test-PDFs, aufgezeichnete Homelab-Antworten und einen Wegwerf-Ordner für geschriebene Notizen. Evals führen den echten Server-Code aus, können aber meine echten Notizen, Dateien und Maschinen weder sehen noch berühren.
