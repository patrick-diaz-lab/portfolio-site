#### Verworfen: das Gateway ins Netz des Workers stellen

Damit wäre jeder Endpunkt des Gateways nur einen Schritt vom Worker entfernt. Der Worker bleibt stattdessen in seinem eigenen Netz, mit einem filternden Proxy als einzigem Weg nach aussen.
