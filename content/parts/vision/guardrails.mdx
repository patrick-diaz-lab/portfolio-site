Most of Vision is written by Claude Code, working on its own inside plans I approve. It follows the written project rules most of the time, but not every time, and the one time it doesn't is usually the expensive one. So the rules don't rest on good behaviour alone: there are checks before a command runs, checks when work leaves for the shared repository, and a merge that only I perform.

This page describes those layers and why each exists. The exact rules stay private: a list of what is blocked, and how, would mostly help someone get around it.
