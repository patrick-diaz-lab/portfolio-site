I want a number before and after every change to a prompt, a model or a tool, measured on cases the thing being improved has never seen. The harness gives me that. It runs the same code the chat runs, against two kinds of sets per eval: dev sets that Claude drafts and I review, and held-out sets that I write myself and agents can't touch.

It covers routing, retrieval over my docs, notes and files, and whole agent answers. The classifier results it produced are on the [agent core page](/vision/agent-core/); retrieval is below.
