The models in Vision answer from my own material: the project's docs, my notes and my PDFs. The knowledge core is what makes that material searchable. An indexer splits each document by its headings, stores a vector and the keywords for every piece, and keeps the index current as documents change. Search runs both rankings and combines them.

None of this can change a note. My notes reach the server in one direction only, private ones never reach it at all, and the models get to the index only through read tools on the [MCP servers](/vision/mcp-servers/). How well it finds things is measured in the [eval harness](/vision/eval-harness/).
