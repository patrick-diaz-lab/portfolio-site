One tier of Vision runs the official Claude Code tool on my subscription instead of the API. It answers only messages I send myself with an explicit command, and it is the one exception to the rule that every model call passes the [gateway](/vision/litellm-gateway/).

Because it is a full agent tool rather than a single model call, it runs inside several layers: its own network, a fresh workspace for every call, a check of what it actually loaded, and the same read-only tools as the strong model. This page names those layers and why each exists; the exact configuration stays private.
