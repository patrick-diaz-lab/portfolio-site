Every message I send to Vision lands in agent core first. It decides who answers: nobody, if the message is a command; a cheap model, if it's simple; a strong model with tools, if it isn't. Every request it sends to the [gateway](/vision/litellm-gateway/) becomes a numbered step in a run, so I can see afterwards what each message cost and what it did.

The tools are search and read over my docs, notes, files and homelab status. Nothing it can call writes anything, and whatever a tool returns reaches the model marked as data, never as instructions.
