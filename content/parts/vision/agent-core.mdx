Every message I send to Vision lands in agent core first. It decides who answers: nobody, if the message is a command; a cheap model (`cheap`), if it's simple; a strong model with tools (`smart`), if it isn't. Every request it sends to the [gateway](/vision/litellm-gateway/) becomes a numbered step in a run, so I can see afterwards what each message cost and what it did.

The tools search and read my docs, notes, files and homelab status. They are read-only, except one that writes notes into the agents' own inbox folder; my own notes stay read-only. Whatever a tool returns reaches the model marked as data, never as instructions.
