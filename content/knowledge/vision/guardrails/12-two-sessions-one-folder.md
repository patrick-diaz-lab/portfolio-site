### Two sessions in one folder

For a few days several Claude sessions shared one working copy. Unfinished files landed on the wrong branch, one session ran commands that had been approved for another item, three pull requests from different starting points couldn't be merged one after another, and a session lost track of what it had already run once its memory was compacted.

Now every session gets its own working copy and branch, made automatically; one locked lane holds anything live; a board shows what waits for me; work is brought up to date before it's called ready; and each session keeps a short record it can recover from. My part of an item came down to approving the plan, doing my own steps, reviewing, and merging.
